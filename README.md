# platform-editor
A port of [*Platform Editor* on Scratch](https://scratch.mit.edu/projects/716444176/), where you have to beat levels by placing various items.

# Instructions
This is a normal Rust project utilizing `SDL3`.

Use `cargo build` to compile the project, or `cargo run` to directly compile and run the project.
